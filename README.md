## 📌 Project Overview
This project demonstrates foundational JavaScript skills through the implementation of small, structured applications. It focuses on writing clean, modular, and reusable code using core language features such as functions, arrays, objects, and control flow.

The goal is to simulate real-world programming patterns by separating logic into independent modules and applying consistent coding structure.

---

## 🚀 Features

### 🧮 Interactive Calculator
A modular calculator built using pure JavaScript functions.

**Capabilities:**
- Basic arithmetic operations (+, −, ×, ÷)
- Modulus and exponentiation
- Division-by-zero handling
- Centralized calculation controller using switch statements
- Clean function decomposition for maintainability

---

### 🎓 Student Grade Tracker
A data-driven system for managing and analyzing student performance.

**Capabilities:**
- Add and store student records dynamically
- Compute individual student averages
- Compute subject-wide class averages
- Identify top-performing student
- Detect students needing improvement
- Generate structured report cards
- Assign letter grades based on performance thresholds

---

## 📚 JavaScript Concepts Applied

- Variables and data types
- Functions (declaration, expression, arrow functions)
- Control flow (if/else, switch, loops)
- Array methods (map, filter, reduce, find)
- Object manipulation and nested data structures
- Functional decomposition and modular design

---

## 🧱 Project Architecture

This project is structured to reflect separation of concerns:

- `js/calculator/` → Pure calculator logic
- `js/grade-tracker/` → Data management and analytics system
- `exercises/` → Practice implementations for core concepts
- `js/main.js` → Entry point and test execution
- `index.html` → Application entry
